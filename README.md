# Result Portal

Ye ek simple web-based result portal hai jisme students apna Roll Number dal kar apna result dekh sakte hain.

## Features
- Roll number input
- Google Sheet se live result fetch
- Responsive design (mobile friendly)
- Hosted via GitHub Pages

## How to use
1. Open the website
2. Enter your Roll Number
3. Click "Submit"
4. See your result

## Technology Used
- HTML, CSS, JavaScript
- Google Sheets as backend database
- GitHub Pages for hosting
